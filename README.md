# Customer Lifetime Value (LTV) Prediction MLOps Project

## Overview

This project is an end-to-end Machine Learning and MLOps pipeline that predicts a customer's future revenue (Customer Lifetime Value - LTV) using historical transaction data from the Online Retail dataset.

The project covers the complete lifecycle of an ML application:

- Data Cleaning & Preprocessing
- Feature Engineering
- Model Training & Evaluation
- REST API Development with FastAPI
- Docker Containerization
- Kubernetes Deployment
- Google Cloud Platform (GCP) Deployment

---

## Problem Statement

Businesses need to identify high-value customers and estimate future revenue generated by each customer.

Using historical transaction data, this project predicts the future revenue a customer is likely to generate, enabling businesses to:

- Identify valuable customers
- Improve customer retention
- Optimize marketing spend
- Personalize customer engagement

---

## Dataset

Dataset: Online Retail II

The dataset contains:

- Customer ID
- Invoice Number
- Product Information
- Quantity Purchased
- Unit Price
- Invoice Date

After cleaning and preprocessing, customer-level features were generated for training the model.

---

## Feature Engineering

### RFM Features

#### Recency
Number of days since the customer's last purchase.

#### Frequency
Total number of purchases made by the customer.

#### Monetary
Total revenue generated by the customer.

---

### Additional Features

#### AvgOrderValue

```python
Monetary / Frequency
```

Average value per order.

---

#### TenureDays

```python
Reference Date - First Purchase Date
```

Customer lifetime in days.

---

#### PurchaseRate

```python
Frequency / TenureDays
```

Purchases per day.

---

#### RecencyRatio

```python
Recency / TenureDays
```

Measures inactivity relative to customer lifetime.

---

## Target Variable

FutureRevenue

Revenue generated by the customer during the prediction window.

Due to heavy skewness in the target variable, a log transformation was applied:

```python
FutureRevenue_Log = np.log1p(FutureRevenue)
```

This significantly improved model performance.

---

## Exploratory Data Analysis

Key observations:

- FutureRevenue was heavily right-skewed.
- Log transformation reduced skewness substantially.
- Frequency showed the strongest positive relationship with future revenue.
- Recency showed a strong negative relationship with future revenue.
- Additional behavioral features improved model performance.
